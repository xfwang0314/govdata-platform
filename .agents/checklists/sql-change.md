# SQL 变更检查清单

## 查询

- [ ] 显式列字段，没有 `SELECT *`、无界查询、N+1 或跨模块 JOIN。
- [ ] 租户条件、逻辑删除和 ABAC 约束完整，未依赖调用方自行传入。
- [ ] JOIN 包含完整关联与租户一致性条件，默认不超过 4 张本模块表。
- [ ] 普通分页最大 100，OFFSET 超过 10000 已改为稳定游标；批量 IN 不超过 500。
- [ ] 动态排序/标识符来自后端白名单，值使用 `#{}`，未使用 `${}` 或危险 SQL Fragment。
- [ ] 核心 SQL 使用真实 MySQL 8 执行并保存 `EXPLAIN ANALYZE`。

## 更新与删除

- [ ] UPDATE/DELETE 有租户、稳定主键/明确 ID 集合和必要乐观锁条件。
- [ ] 动态条件为空时明确拒绝，不会退化为全表操作或 `WHERE 1=1`。
- [ ] 单条影响行数严格校验；并发冲突和不存在映射为稳定 ErrorCode。
- [ ] 只更新用例允许字段，没有整个 Entity 无差别回写。
- [ ] 物理删除、逻辑删除、撤销和归档语义明确；大批清理由所属模块分批执行。

## 事务与安全

- [ ] 事务位于 ApplicationService，且不包含 JDBC/SFTP/Redis/HTTP/SeaTunnel 等外部调用。
- [ ] 多行更新按稳定主键顺序；重试只针对幂等用例的死锁/锁超时且最多 3 次。
- [ ] 凭据、敏感参数、完整 SQL 参数和查询结果未进入 SQL、日志或升级脚本。
- [ ] 约束异常、超时、死锁和连接失败映射为不同稳定 ErrorCode。

## 脚本与验证

- [ ] Baseline/Upgrade 是唯一可执行事实来源，没有在 docs 或根目录复制 SQL。
- [ ] 写入 `sys_menu` 等脚手架表时，列名已与当前 `00_ruoyi.sql` 逐项核对，没有混入其他版本字段。
- [ ] 新增 Baseline 的分段注释、字段换行、缩进和表选项与现有基线保持一致。
- [ ] Upgrade 文件名、前置脚本、影响行数、锁风险、检查和修复方案完整。
- [ ] 已发布 Upgrade 未修改；破坏性变更使用分阶段兼容迁移。
- [ ] 已运行 SQL 静态门禁、目标模块测试和真实 MySQL 8 集成测试。
