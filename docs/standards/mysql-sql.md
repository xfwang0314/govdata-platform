# MySQL 8 与 SQL 规范

- 状态：v1（强制）
- 适用范围：平台控制库
- 所有者：GovData Platform Team
- 最后更新：2026-08-01

平台控制库只正式支持 MySQL 8；外部多数据源支持不等于控制库多方言支持。

## 命名与字段

- 表使用领域前缀和单数语义：`gd_metadata_*`、`gd_quality_*`、`authz_*`。
- 内部主键使用 bigint 雪花 ID；跨模块引用使用稳定业务编码或稳定 ID。
- 租户业务表按需要包含 tenant_id、version、审计字段和 del_flag；日志/运行记录按追加写模型裁剪。
- 时间使用 `datetime(3)`，精确数值使用 decimal，状态保存稳定字符串 code。
- JSON 只保存注册的扩展属性，核心关系必须建表。

## 查询与索引

- 禁止 `SELECT *`；分页必须有稳定排序。
- 租户表的唯一索引和常用索引通常以 tenant_id 开头。
- 更新和删除必须带可信租户/主键条件。
- 平台业务表统一不建立数据库物理外键；跨表引用保留 `tenant_id`、稳定 ID、唯一索引和查询索引，
  由领域应用服务、事务、对账任务与集成测试保证引用完整性。
- 跨领域不跨表 JOIN 业务表，只通过稳定 ID、契约或事件协作。
- 所有字段写 COMMENT，但正式含义以领域词汇和数据字典为准。
- 应用值使用参数绑定，禁止字符串拼 SQL。
- 大表 DDL、索引和批量更新必须评估锁、回滚和执行窗口。

Entity 可以使用持久化基类；DTO、BO、VO 不得继承。审计、事件和运行历史不得物理覆盖。
