# 数据共享

- 状态：领域词汇 v1
- 适用范围：数据共享上下文
- 所有者：GovData Platform Team
- 最后更新：2026-08-01

数据共享上下文管理同一租户内部门之间的数据申请、审批、协议、订阅和交付。

## Language

**Sharing Catalog Item**:
提供部门发布的、可申请使用的数据集、API 或文件条目。
_Avoid_: Metadata Asset

**Sharing Request**:
使用方针对资源、用途、期限和交付方式提出的申请。
_Avoid_: Authorization Grant

**Sharing Agreement**:
审批完成后形成的双方责任、用途、期限和约束约定。
_Avoid_: Policy

**Sharing Subscription**:
使用方对已发布数据服务的有效订阅关系。
_Avoid_: API Token

**Delivery Plan**:
通过在线查询、API、文件或数据交换完成共享的交付安排。
_Avoid_: Exchange Job
