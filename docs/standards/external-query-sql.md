# 外部数据源受控查询 SQL 规范

- 状态：v1（强制）
- 适用范围：`govdata-query`、外部数据源查询 Adapter、API、Agent 与 MCP 查询入口
- 所有者：GovData Platform Team
- 最后更新：2026-08-04

本文只约束外部数据源在线只读查询。平台控制库遵循 [MySQL 8 与平台控制库 SQL 规范](mysql-sql.md)，
批量数据交换统一委托 SeaTunnel，不得借在线查询能力实施批量搬运。

## 1. 安全模型

```text
调用主体
  → RBAC
  → 租户边界
  → Resource 定位
  → ABAC/Grant 决策与 Obligation
  → 元数据 Schema 白名单
  → 结构化查询 AST
  → 方言 Adapter
  → 只读账号执行
  → 脱敏与审计
```

- 默认拒绝；租户、RBAC、ABAC、Grant 和资源状态任一失败都不得执行查询。
- 数据库只读账号是第一道边界；JDBC `readOnly` 和应用 SQL 校验是附加保护。
- 管理员、Agent 和 MCP 不拥有原始 SQL 或绕过授权的特殊入口。
- 查询审计记录结构化摘要，不保存完整结果和敏感绑定值。

## 2. 禁止原始 SQL

- 页面、API、模块、Agent 和 MCP 均不得提交 SQL 字符串或 SQL Fragment。
- 调用方只能提交结构化模型：资源 ID、字段、过滤、排序、分页和受控聚合。
- 表名、列名只来自已注册元数据 Schema；禁止调用方提供任意标识符。
- 操作符使用封闭枚举；值始终参数绑定。
- ABAC 行过滤必须是结构化 AST/Obligation，禁止策略返回 SQL、SpEL、Groovy 或 JavaScript。
- 最终只允许单条 SELECT；禁止 DDL、DML、多语句、注释逃逸、过程调用和管理命令。
- 排障 SQL 通过平台外的受控数据库运维流程执行。

## 3. 第一版查询能力

- 单次查询只允许一个已注册资源，第一版不支持跨表 JOIN。
- 默认最多 100 行，硬上限 1000 行；禁止无行数限制查询。
- 默认超时 10 秒，硬上限 30 秒。
- 最多选择 100 个字段、50 个过滤条件、5 个排序字段。
- IN 最多 500 个值，条件嵌套最多 5 层。
- 排序字段必须在字段白名单内，并追加稳定唯一键保证分页稳定。
- 禁止系统库、系统 Schema、临时表、未注册对象和跨 Schema 探测。
- 导出、全量读取和大批量传输不得通过提高上限实现，必须进入独立任务/SeaTunnel。

这些是平台硬上限。Connector 可以设置更严格的限制，不能放宽硬上限；请求参数不得修改上限。

## 4. 结构化过滤

第一版允许的操作符由 API 契约枚举确定，例如：

- `EQ/NE`
- `GT/GE/LT/LE`
- `IN/NOT_IN`
- `BETWEEN`
- `LIKE/STARTS_WITH`
- `IS_NULL/IS_NOT_NULL`

规则：

- 操作符必须与元数据字段类型兼容。
- LIKE 默认不允许前导通配符；包含搜索需 Connector 能力和复杂度评审。
- NULL 判断不得转换成 `= NULL`。
- 时间值必须携带明确来源时区，在 Adapter 边界转换。
- Decimal、日期和 Boolean 使用类型化绑定，禁止先转字符串再比较。
- 调用方过滤与 ABAC 行过滤使用 AND 合并；DENY 优先，不允许客户端覆盖系统条件。
- Column Mask 在返回结果前按授权 Obligation 执行，未经授权字段不得进入执行列清单。

## 5. 方言 Adapter

- 通用 Application 层不得出现 `if (mysql/oracle/clickhouse)` 方言分支。
- MySQL、Oracle、Doris、ClickHouse 分别由 Adapter 生成引用符、分页、参数和类型转换。
- Adapter 输入是已校验 AST 和 Schema，输出是 SQL 模板与绑定参数，不能接受原始 SQL。
- 标识符必须来自 Schema 白名单并按方言安全引用；值禁止拼接。
- 方言能力明确声明支持的操作符、类型、排序、聚合和限制方式；不支持时稳定拒绝。
- Adapter 合同测试覆盖特殊标识符、保留字、Unicode、NULL、时间、Decimal、IN 上限和注入载荷。
- Redis、SFTP 不伪装成 SQL 方言，使用各自专用只读能力模型。

## 6. 执行保护

- 数据源必须为 ACTIVE、连接测试有效且授权资源状态可用。
- 查询账号在外部数据库侧只授予所需对象 SELECT 权限。
- JDBC 设置只读、查询超时、fetch size、最大行数和取消能力。
- 连接池按数据源/租户设置并发与等待上限，禁止单一慢源耗尽平台线程。
- 超时、取消、结果超限、连接失败、权限失败和方言不支持使用不同稳定 ErrorCode。
- 连接失败不进行无限重试；只有明确瞬时错误可在整体超时内有限重试。
- 明显全表扫描、超大范围、无有效过滤或高复杂度查询可以在执行前拒绝。
- 结果达到硬上限必须明确标记截断，不能伪装为完整数据。

## 7. 日志与审计

允许记录：

- tenant、主体类型/ID、资源 ID、动作、授权决策 ID。
- 字段数量、过滤条件数量、返回行数、耗时、Connector、稳定结果码和 traceId。
- 规范化 SQL 模板或结构摘要（仅受控技术日志）。

禁止记录：

- 原始凭据、连接密码、Token 和私钥。
- 完整绑定参数、身份证号等敏感过滤值。
- 完整查询结果、未脱敏服务端错误和 JDBC URL 密码部分。
- Agent/MCP 原始上下文中与查询无关的敏感内容。

生产外部慢查询初始阈值为 3000ms；阈值配置化但不能由请求修改。

## 8. 测试门禁

- 通用 AST 测试覆盖操作符、类型、复杂度、上限和 ABAC 条件合并。
- 每个方言 Adapter 使用对应真实数据库/兼容测试环境执行合同测试。
- 安全测试覆盖注释、多语句、标识符注入、排序注入、超大 IN、深嵌套和越权字段。
- 集成测试验证 RBAC、租户、ABAC/Grant、Column Mask、行过滤、超时、取消与审计。
- 不以 H2 代替 MySQL/Oracle/Doris/ClickHouse 方言验证。
- 新查询能力或操作符必须同步更新 API 契约、方言矩阵、测试和本文档。
