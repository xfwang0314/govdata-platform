# 日志与审计规范

- 状态：v1（强制）
- 适用范围：应用日志、操作、授权、访问和运行审计
- 所有者：GovData Platform Team
- 最后更新：2026-08-01

- 技术日志、操作审计、授权审计、数据访问审计和引擎运行日志分开。
- 所有链路记录 traceId；后台运行增加 runId；Agent 调用增加 taskId/delegationId。
- 使用稳定 reasonCode/errorCode，消息用于阅读而非机器判断。
- 禁止记录密码、Token、私钥、完整连接串、完整身份证、完整结果集。
- 查询参数中的敏感值脱敏或只记录指纹。
- 审计追加写，不更新、不逻辑删除；按类型设置保留和归档。
- 成功、失败、拒绝和撤销均需记录；高风险操作触发告警。
- 日志使用参数化占位符，禁止为调试拼接敏感对象的 toString。
- 高风险操作在审计不可可靠写入时默认失败或进入可靠缓冲。
