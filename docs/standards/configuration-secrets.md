# 配置与凭据规范

- 状态：v1（强制）
- 适用范围：local、dev、test、prod 配置和 Secret
- 所有者：GovData Platform Team
- 最后更新：2026-08-01

- 同一 Commit 构建一次，同一制品部署到所有环境。
- 环境差异通过环境变量、挂载配置或 SecretProvider 外部化，不通过条件业务代码。
- 仓库只保存安全模板和非敏感默认值；生产禁止默认密码和开发密钥。
- 配置项具有稳定前缀、类型、说明和启动校验；关键配置缺失时快速失败。
- 数据源业务表只保存 secretRef；前端不回显旧 SecretValue。
- Secret 按租户、类型、版本、状态和有效期管理，读取记录用途和 traceId。
- 第一阶段不强制配置中心；后续以 Adapter 接入。
- Docker Compose 只用于本地/测试辅助；生产部署需健康、存活和就绪探针。
- 日志级别、连接池和超时可按环境调整，授权和业务规则不得随环境改变。
