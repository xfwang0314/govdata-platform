# 新表检查清单

## 归属与类型

- [ ] 表有唯一模块所有者、正确领域前缀，并登记到表所有权文档。
- [ ] 已声明业务实体、关系/明细、配置/版本、任务/运行或追加记录类型。
- [ ] GLOBAL 表有明确白名单依据；其他表均包含非空 `tenant_id`。
- [ ] 没有物理外键、跨模块 JOIN、跨模块表复制或访问其他模块 Mapper。

## 字段

- [ ] 使用有符号 bigint 雪花主键，名称为 `{entity}_id`，未使用 AUTO_INCREMENT/UUIDv4。
- [ ] 需要稳定引用的实体由后端生成“登记前缀 + 雪花 ID Base36”编码，Command 不接收该编码。
- [ ] 字段类型、长度、NULL 和默认值符合 `mysql-sql.md`，没有无依据 `varchar(255)`。
- [ ] 时间为 `Asia/Shanghai + datetime(3)`，机器编码使用 `ascii_bin`。
- [ ] `status/del_flag/lock_version` 各自语义明确，没有用删除标志代替生命周期。
- [ ] 审计字段与表类型匹配；追加表没有机械复制更新审计字段。
- [ ] JSON 已定义 Schema、版本、尺寸和敏感字段拒绝；核心关系/筛选字段未藏入 JSON。
- [ ] 文件、大文本、凭据和个人敏感数据符合对象存储、secretRef 和脱敏规则。

## 约束与索引

- [ ] 表、字段、索引、CHECK 均有规范名称与 COMMENT。
- [ ] 封闭值、Boolean、数值范围和单行不变量有命名 CHECK，未使用 ENUM/SET。
- [ ] 业务唯一性有 UNIQUE 兜底，唯一字段非空且以 `tenant_id` 开头。
- [ ] 已列出核心查询、排序和对应索引；分页排序末尾包含唯一主键。
- [ ] 没有低基数单列、左前缀重复或无查询证据索引；二级索引超过 5 个已有专项说明。
- [ ] 核心查询已有 `EXPLAIN ANALYZE` 证据。

## 生命周期与容量

- [ ] 已定义创建、启停、发布、撤销、归档、删除和并发冲突语义。
- [ ] 高增长表已估算日增量/行宽，并明确在线、归档、清理、法规期限和责任模块。
- [ ] 追加记录只允许 INSERT；清理有稳定索引、批次、指标和告警。

## 交付

- [ ] 已同步 Baseline、不可变 Upgrade、manifest、Entity、Mapper、Validation 和领域文档。
- [ ] Upgrade 具有完整头部、锁风险、前后检查和前向修复/回滚说明。
- [ ] 已通过 SQL 静态检查和真实 MySQL 8 Schema/Mapper 集成测试。
- [ ] Controller 不返回 Entity；跨模块契约不暴露持久化对象。
